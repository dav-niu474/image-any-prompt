## ✨ 功能特色

- 🖼️ **提示词图库** - 浏览和搜索 164 条精选 AI 图像提示词，每条均附带真实生成图例
- 🖼️ **示例图片展示** - 从源仓库提取的真实 GPT Image 生成效果图片，直观展示提示词效果
- 🎯 **应用场景分类** - 按 13 种应用场景（电商、社交媒体、品牌设计等）筛选提示词
- 🏷️ **多维度筛选** - 支持按类别（19 种）、来源（4 个仓库）、场景三维筛选
- ✨ **AI 智能生成** - 基于 NVIDIA Llama 3.3 70B 模型智能生成提示词，支持多模型自动降级
- 📋 **一键复制** - 快速复制提示词到剪贴板
- 🔍 **全文搜索** - 搜索标题、提示词内容和标签
- 📱 **响应式设计** - 适配桌面和移动设备
- 🌙 **深色主题** - 舒适的深色界面设计，翡翠绿点缀
- 📜 **历史记录** - 本地保存生成历史，随时回溯

## 🤖 AI 提示词生成

本项目集成了 NVIDIA API 模型服务，支持智能提示词生成：

### 模型优先级链

按以下顺序尝试模型，直到成功响应：

| 优先级 | 模型 | 说明 |
|--------|------|------|
| 1 | `meta/llama-3.3-70b-instruct` | 主力模型，性能稳定 ✅ |
| 2 | `nvidia/llama-3.1-nemotron-70b-instruct` | 备选模型 |
| 3 | `deepseek-ai/deepseek-v4-flash` | 轻量备选 |
| 4 | `gpt-4o-mini` (via z-ai-web-dev-sdk) | 最终兜底 |

### 支持的生成参数

| 参数 | 可选值 |
|------|--------|
| 风格 | Photography, Illustration, 3D Render, Anime, Sketch, Watercolor, Pixel Art, Cyberpunk, Chinese Ink, Minimalist, Poster, UI Design |
| 应用场景 | 13 种场景可选 |
| 内容类别 | 19 种类别可选 |
| 宽高比 | 1:1, 3:4, 4:3, 9:16, 16:9 |
| 画质等级 | Standard, High, Ultra |
| 输出语言 | English, 中文, 日本語 |

### 提示词工程原则

AI 生成提示词时遵循以下专业原则：

- 极致具体的视觉细节（光照、构图、色彩、材质、纹理）
- 包含风格引用和美学描述词
- 摄影类指定相机角度、镜头类型（如 35mm, 85mm portrait lens）
- 精确的光照描述（如 soft butterfly lighting, golden hour backlighting）
- 指定宽高比和画质参数（如 8K resolution, high detail）
- 文字排版类指定字体风格和布局层级
- UI 设计类描述具体界面元素和标签
- 精确的调色板描述（如 Forest Green dominant, Matte White, Kraft Paper Brown）

## 🚀 快速开始

### 环境要求

- Node.js 18+ 或 Bun
- NVIDIA API Key（用于 AI 提示词生成，可选）

### 安装依赖

```bash
npm install
# 或
bun install
```

### 配置环境变量

创建 `.env.local` 文件：

```env
NVIDIA_API_KEY=your_nvidia_api_key
```

> 💡 如果不配置 `NVIDIA_API_KEY`，AI 提示词生成功能将自动使用 `gpt-4o-mini` 作为兜底模型。

### 启动开发服务器

```bash
npm run dev
# 或
bun run dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看效果。

### 构建生产版本

```bash
npm run build
npm run start
```

## 📝 数据结构

### 提示词 (Prompt)

```typescript
interface Prompt {
  id: string;           // 唯一标识，如 "nano-1", "youmind-3", "zerolu-2"
  title: string;        // 标题
  category: string;     // 内容类别（19 种）
  scenario: string;     // 应用场景（13 种）
  tags: string[];       // 标签列表
  prompt: string;       // 完整提示词文本
  source: string;       // 数据来源（opennana-nano / awesome-gpt-image / awesome-gpt-image-2）
  imageUrl: string;     // 示例图片 URL（来自源仓库的真实生成效果）
}
```

### 图片来源域名

示例图片托管在以下 CDN 上：

| 域名 | 来源 |
|------|------|
| `zhenglarry007.github.io` | OpenNana Gallery（GitHub Pages） |
| `cms-assets.youmind.com` | YouMind CDN |
| `pbs.twimg.com` | Twitter/X 媒体 |
| `github.com` / `raw.githubusercontent.com` | GitHub 用户上传附件 |

## 🔧 关键配置

### Next.js 图片域名白名单

由于示例图片托管在外部 CDN，需要在 `next.config.ts` 中配置 `remotePatterns`：

```typescript
images: {
  unoptimized: true,
  remotePatterns: [
    { protocol: "https", hostname: "zhenglarry007.github.io" },
    { protocol: "https", hostname: "cms-assets.youmind.com" },
    { protocol: "https", hostname: "pbs.twimg.com" },
    { protocol: "https", hostname: "github.com" },
    { protocol: "https", hostname: "raw.githubusercontent.com" },
    { protocol: "https", hostname: "user-images.githubusercontent.com" },
  ],
}
```
